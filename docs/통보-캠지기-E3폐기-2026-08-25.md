# [통보] 스펙 E3 폐기 — 동반 인원 필수 해제

**보내는 곳** 크리에이터 포털 (`influencer-portal`)
**받는 곳** 캠지기측 (`camjigi_claude` / `camfit-premium`)
**작성** 2026-08-25 · **커밋** `23dd972`

> 🔴 **그쪽 심사 체크리스트 1번 항목이 무효가 됩니다.** 그대로 두면 정상 프로필을 반려하게 됩니다.

---

## 1. 무엇이 틀렸나

E3는 이 전제 위에 서 있었습니다.

> "2인용 사이트에 4명이 오면 그날 밤은 이미 망한다. 사이트 정원은 물리적 제약이다"
> → 그러니 동반 인원은 표준으로 못 덮고, 공개 게이트 필수여야 한다

**전제가 사실이 아닙니다.**

실제 구조는 수락 전에 해당 캠핑장 쿠폰을 크리에이터에게 주고, **크리에이터가 그 쿠폰으로 직접 예약**합니다(프리미엄 협찬과 동일). 캠지기가 사이트를 인원에 맞춰 잡아두는 절차가 없습니다.

그리고 인원은 방문마다 달라집니다 — 가족과 갈 때도 있고 혼자 갈 때도 있습니다. 프로필에 한 번 못박아 받으면 **틀린 숫자를 받게 되고, 그 숫자가 캠지기 카드에 사실처럼 뜹니다.** 없는 것보다 나쁩니다.

## 2. 포털이 바꾼 것

| | 변경 |
|---|---|
| `collectMissingForPublish` | 제거 — **공개 게이트 아님.** 비어 있어도 공개 신청됩니다 |
| `computeCompletion` | 항목 제거 — 안 채워도 미완성 아님 |
| 라벨 | `동반 인원 *` → `동반 인원 (선택)` |
| 범위 검증 | **유지** (1~10 정수) — 오타 `999`가 카드에 뜨는 것만 막는 용도 |

안내 문구:

```
before  본인 포함 몇 분이 방문하시나요? 캠지기가 사이트를 이 인원에 맞춰 잡아둡니다.
after   보통 몇 분이 함께 가시나요? 캠지기가 참고만 하는 정보라 방문마다 달라져도 괜찮아요.
        예약은 받으신 쿠폰으로 직접 하시게 됩니다.
```

**Airtable `동반 인원` 필드는 그대로 씁니다.** 읽기·쓰기 경로 변경 없습니다. 값이 있으면 `buildVisitConditionSummary`가 `4인 방문 · 반려동물 동반`으로 계속 렌더합니다. 달라진 건 **필수가 아니라는 것 하나**입니다.

## 3. 그쪽에 필요한 조치

1. 🔴 **심사 체크리스트 1번 삭제** — "동반 인원 비어 있으면 승인하지 말 것"
   (`camjigi_claude/docs/[ops] 지명형_프로필심사_체크리스트_20260825.md`)
2. 캠지기 카드에서 **동반 인원이 빈 값일 때 깨지지 않는지** 확인 부탁드립니다. 이제 빈 값이 정상입니다

---

## 4. 부수 효과 — 지난 (a)/(b)/(c) 논의가 무의미해졌습니다

"동반 인원 0인 레거시" 문제 자체가 사라집니다. 게이트에 없으니 레거시가 저장에 막힐 일도, 승인 후 다른 항목만 고치려다 막힐 일도 없습니다.

**(c) 위반 코드 한국어 매핑은 그대로 둡니다** — 나머지 10종에 여전히 쓸모가 있습니다.
