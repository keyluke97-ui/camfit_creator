## 0. 한 줄

## 1. 왜 재설계하나

1a(2026-07-20 완료, 미배포)는 "리스트에 뜨고 가격이 계산되는" 최소 조건을 만족했다. 배포 직전 두 방향에서 요구가 들어왔다.

**캠지기측(2026-08-11 요청서)** — 캠지기 화면을 실데이터로 점검하니 카드가 비었다. 블로그 크리에이터 108명 중 79명이 지표 0, 유튜브 106명 중 69명이 구독자 수만 있다. 그리고 캠지기가 "무엇을 사는지"(채널·산출물 형식)가 확정되지 않아 그대로 분쟁이 된다.

**사용자(2026-08-11 세션)** — 제안 수락 흐름·유류비 노출 시점·단가 의미·지표 신뢰성에 대한 UX 요구.

지명형은 **캠지기가 선입금한 뒤** 크리에이터를 만난다. 캠핏이 중간에서 조율할 여지가 공모형보다 좁아, 사전 정보가 곧 분쟁 예방선이다.

| D9 | **최초 1회만 노출을 막는 심사. 이후 수정은 재검토 큐로만** | 수정할 때마다 노출을 끊으면 캠지기측 확정 사항 "상시 수정 가능"과 충돌하고 운영이 마비된다. 재검토 대상도 지표·표시물로 한정한다 |
| D10 | **1a / 1b 분리** | 프로필이 있어야 제안이 오고, 제안이 있어야 확인 화면이 의미가 있다 |

### 폐기된 대안

- **자동수락을 디폴트 ON으로 두는 안** — 검토 중 "자동수락"의 실제 의미가 확인되어 소멸했다. `자동수락 활성` 플래그는 "확인창 없이 즉시 확정"(인스턴트북)을 뜻하는데, 실제 확정된 흐름은 "확인창 + 무응답 자동확정"이다. 후자가 이미 전원 기본값이므로 플래그 자체가 불필요하다.
- **지표 경고 문구만 두고 사후 제재** — 선입금 구조에서는 터졌을 때 이미 돈이 나간 뒤다.
- **이상치만 자동 검출해 사람이 보는 안** — 운영 부담은 적으나 사용자가 전수 심사를 선택했다.

## 4. 심사 흐름 (신규)

### 4.1 상태 기계

```
미신청 ──[공개 신청]──> 심사대기 ──[운영자 승인]──> 승인 ──> 캠지기에게 노출
                          │
                          └──[운영자 반려]──> 반려 (사유 표시) ──> 재신청 가능

승인 ──[지표·표시물 수정]──> 승인 유지 + `지표 재검토 필요` = true
                            (노출은 계속, 운영자 재검토 큐에 진입)
                            운영자 확인 → 체크 해제 또는 반려로 전환
승인 ──[그 외 항목 수정]──> 승인 유지, 즉시 반영
```

**최초 진입은 100% 심사를 거친다.** 승인 이후의 수정은 노출을 끊지 않고 재검토 큐로만 보낸다.

- **왜 이렇게 하나**: 재심사 중 노출을 끊으려면 "승인된 값"을 따로 보관해야 하고, 그러면 캠지기측이 원본이 아닌 스냅샷을 읽도록 **읽기 경로를 바꿔야 한다.** 협의 비용과 버그 표면이 커진다
- **감수하는 위험**: 승인 후 지표를 부풀리면 운영자 확인 전까지 잠깐 노출된다. 다만 ① 최초 심사를 통과한 사람이고 ② 즉시 재검토 큐에 뜨며 ③ 적발 시 제재 대상이라 위험이 제한적이다
- **미신청·반려 상태에서는 어떤 값도 캠지기에게 노출되지 않는다**

### 4.2 재심사 트리거 (D9)

| 수정한 항목 | `지표 재검토 필요` 플래그 |
|---|---|
| 자기신고 지표 6종 · 채널별 URL 3종 · `채널 종류` · `대표 채널` | ✅ 켠다 |
| 프로필 이미지 · 대표 콘텐츠 링크 1~3 · 채널 강점 | ✅ 켠다 (표시물이라 검토 대상) |
| 방문 가능 지역/요일 · 수용 사이트 종류 · 협찬 금액 · 원정 · 제작 콘텐츠 형식 · 제작 기준 · 이메일 | ❌ 안 켠다 |

**핵심 불변식**
1. `프로필 심사 상태 = 승인`을 한 번도 받지 못한 프로필은 캠지기에게 **절대 노출되지 않는다**
2. 승인 이후의 수정은 **노출을 끊지 않는다.** 플래그만 켜서 재검토 큐로 보낸다
3. 심사 상태와 플래그는 **서버만 쓴다.** 크리에이터 payload로는 변경 불가

### 4.3 캠지기측 필터 변경 (회신 필요)

현재 캠지기 리스트 필터: `프로필 공개 = true` AND `휴먼 상태 ≠ true`
변경 후: **`+ AND 프로필 심사 상태 = 승인`**

이 한 줄이 빠지면 심사 전 프로필이 그대로 노출되어 D8이 무효가 된다.
